## Emberwild 0.8.1: dev build tools

**Downloads:**
- `Emberwild-0.8.1-windows.zip` is the game.
- `Emberwild-0.8.1-windows-dev.zip` is the game plus the developer tools.

### Dev build
- **Everything unlocked:** the Mage, the Priest, every relic and all ten Ember levels. The dev build keeps its own save file (`save-dev.json`), so testing never touches your real progress.
- **Dev menu:** press **F1** during a run. The cursor is freed while it's open and the run keeps going behind it.

| Group | Buttons |
|---|---|
| Player | God mode, No cooldowns, Full heal, +1 or +5 levels, +500 run gold, Drop a chest, +3 rerolls |
| Build | Max every relic, All ability and weapon upgrades, Random chaos augment, Swap weapon |
| Run | +1 minute, Go to just before each boss (Golem, Colossus, Broodmother, Ember King), Time of day +6h, Spawn a horde, Kill everything |
| Bosses | Spawn any of the four |
| Events | Start any event (challenge, cursed shrine, treasure goblin, war totem, merchant), +1000 Camp gold |

The player build is unchanged from 0.8.0.
